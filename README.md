# UniBridge v1

Marketing website for UniBridge: "Where futures cross over".
Separate project from RWD Global (nothing here shares a repo, domain or deploy with it).

- Static HTML/CSS/JS, no build step. Open `index.html` or deploy the folder as-is.
- Hosting: Netlify (`netlify.toml`); contact form uses Netlify Forms (name "inquiry").
- Palette: logo blue #1F4FD8, navy #10223D, mint #2DD4BF, neutral #F4F6FA. Flat colours.

- Open items: partner university list (left empty for now), real photos (currently hotlinked Unsplash), domain unibridge.ae.
